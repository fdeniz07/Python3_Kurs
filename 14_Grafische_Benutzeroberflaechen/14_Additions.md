# Kapitel 14 — Ergänzungen

Dieses Dokument fasst neue Inhalte zusammen, die dem Kapitel `14_Grafische_Benutzeroberflächen` hinzugefügt wurden: Referenzen zu Widget-Methoden und Layout-Optionen sowie mehrere kleine Beispielanwendungen zum Lernen durch Bauen.

## Neue Abschnitte

- Gemeinsame Methoden der Widgets: kurze Referenz (after, bell, cget, config, destroy, grid, pack)
- Das Layout verfeinern: Pack / Grid / Place Hinweise (anchor, expand, fill, padx, pady, side)
- Raster-Layout: Grid-Optionen (column, columnspan, row, rowspan, padx, pady)

Die obigen Referenzen sind in kompakten Textformulierungen verfügbar; für ausführliche Erklärungen siehe die jeweiligen Notebooks im Ordner.

## Beispielskripte (neu)

Die folgenden, einfachen Beispielskripte wurden hinzugefügt in `14_Grafische_Benutzeroberflächen/examples/`:

- `grid_coloring.py` — automatisches Farbfelder-Bild (Canvas mit farbigen Kästchen)
- `reimen_goethe.py` — kleines GUI, das zufällige Goethe-Zeilen anzeigt
- `currency_converter.py` — einfacher Währungsrechner (fest eingestellte Wechselkurse)
- `text_editor.py` — minimaler Texteditor mit Menü (Öffnen, Speichern)
- `color_mixer.py` — RGB-Schieberegler und Farbvorschau
- `bremsweg.py` — Bremsweg-Rechner mit Eingabefeldern
- `stopwatch.py` — einfache Stoppuhr (Start/Stopp/Reset)

## Nutzung

Die Skripte sind eigenständige Programme. Aus dem Ordner `14_Grafische_Benutzeroberflächen/examples/` können sie mit Python gestartet werden:

```powershell
python 14_Grafische_Benutzeroberflächen\examples\grid_coloring.py
```
